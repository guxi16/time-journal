# 时间笔记 (Time Journal) — 产品规格说明书 v1.0

## 产品定位
一个帮助用户建立规律作息的**被动时间记录伙伴**。核心不是"看守"，而是"见证者"——通过主动问询记录日常、睡前回顾给予正反馈、奖惩机制激励坚持，最终让用户有意识地管理自己的时间和作息。

## 目标用户
- 自控力较弱，普通闹钟/日历提醒无效
- 晚上灵感多、容易熬夜，白天感觉"什么都没做"
- 需要外部提醒和正向反馈来建立作息规律
- **用户称呼**：顾顾（产品中所有文案使用此称呼）

## 核心功能

### 1. 定时问询（白天记录）
- 默认每 2 小时主动弹出，频率可调（1h/2h/3h/手动）
- 晚上 8 点后切换语气："顾顾，今天过得好吗？"
- **强制记录**：弹窗无关闭按钮（×），必须选择一种记录方式回应，或使用"跳过"
- **跳过限制**：每日 3 次额度，用完必须回应
- **未回应重弹**：弹窗无操作 → 10 分钟后重弹 → 30 分钟后重弹 → 持续追问直到回应
- **预设按钮**：点击即可记录，无需打字
  - 🎨画画 🎮游戏 📺看视频 💻写代码 📚学习 📱刷手机 🛒购物 🧹家务 🍜吃饭 💬社交 ✍️其他
  - 选"其他"才弹出文本框
- **三种记录方式**：
  - 💬说两句：自由文字
  - 📷拍照：调用相机/相册，**必须填主题（一句话）**，补充说明可选
  - 🔗贴链接：输入 URL，**必须填主题（一句话）**，补充说明可选
- 支持手动补记
- 根据昨晚睡眠情况，早上第一句自动适配语气（正常/熬夜/严重熬夜）
- **日期边界**：凌晨 4:00 之前算"昨天"

### 2. 灵感管理（晚间刹车）
- 晚间（20:00-01:00）检测到用户活跃时弹出
- 标题："你现在有一件很想做的事对吧？"
- 三个选项：
  - 📦 存档明天：记录想法 → 第二天首页首屏展示 → 可标记"已完成"
  - ⏱ 设倒计时：选择时长（15/30/45/60分钟）→ 到点弹出提醒
  - 🏃 直接去做：不拦，但记录标记，明早提示"昨晚又上头了"
- 存档超过 3 天未完成自动归档

### 3. 睡前回顾页
目标入睡时间到达后，回顾页（底部导航第二个 Tab）自动展示：

**上半部分：今日数据**
- 标题："今天不是空白" + 记录条数
- 时间线列表：每条显示时间 + 类型图标 + 内容
- 无记录时："今天放空了。偶尔放空也很好 🌸"
- 熬夜原因追踪（5 选 1 按钮）：💡灵感创作 / 🎮游戏视频 / 😰焦虑空虚 / 🥱不困 / ✍️其他
- 选后可补充文字

**下半部分：还不想睡？**
- 四个入口（主动点击，不自动弹）：
  - 💬 树洞：预设回复聊天（v1.0），有上下文感知（读取当天时间线数据）
  - 🃏 塔罗：每日一抽，随机牌 + 简短解读（小仪式感）
  - 🌬️ 呼吸：4-7-8 呼吸法动画引导（圆变大变小，跟节奏呼吸）
  - 🎵 音乐：内置白噪音/轻音乐播放

### 4. 洗澡提醒
- 可设时间窗口（默认 22:30-23:30）
- 到达窗口起始时间弹出："该洗澡啦 🚿"
- 按钮：✅已洗 / ⏰等会儿
- 等会儿 → 15 分钟后重弹
- 已洗 → 时间线自动记录
- 防敷衍：回答"已洗"但距上次弹窗不足 3 分钟 → 追问"这么快？真的洗了吗 🌚"

### 5. 奖惩机制
**奖励**：
- 连续 3 天早睡 → 🌟 早睡之星
- 连续 7 天早睡 → 🏆 作息守护者
- 起床时间连续 5 天稳定（±1h）→ 📊 生物钟稳定
- 一天主动记录 ≥3 次 → 🌱 自我觉察

**温和代价**：
- 熬夜后次日 → 界面顶部提示"今天多关照自己"
- 连续熬夜 3 天 → 弹出输入"我知道昨晚又熬夜了"，必须输入确认
- 熬夜后次日 → 问询频率自动 ×2（仅一天）

### 6. 风格模式
四种可选模式，所有文案语气切换：

| 场景 | 温柔 | 严格 | 搞笑 | 简约 |
|------|------|------|------|------|
| 白天问询 | "顾顾，刚才在干嘛呀？" | "两小时了，汇报进度" | "皇上，该禀报政绩了" | "做了什么？" |
| 睡前回顾 | "今天辛苦了，可以睡了" | "时间到。现在去睡。" | "南瓜马车要回收了" | "该睡了" |
| 熬夜后 | "没关系，明天重新来" | "又熬夜了。输入原因。" | "是谁又做贼了 🕵️" | "熬夜了" |

### 7. 长期成长
- 每周安心信（周日晚上自动生成）：本周总结 + 熬夜模式统计 + 下周小建议
- 作息趋势图：Canvas 绘制的近 7/14/30 天入睡起床折线图
- 熬夜模式分析：基于原因追踪统计"这周多因灵感熬夜"

## 技术方案
- **平台**：纯前端 PWA
- **部署**：GitHub Pages
- **存储**：localStorage（单设备本地，清除浏览器数据即丢失）
- **通知**：JavaScript 定时器 + 页面保持前台（浏览器无法后台推送系统通知）
- **技术栈**：原生 HTML + CSS + JavaScript，零依赖，无需 npm/build
- **AI 功能**：v1.0 不集成 AI API，树洞使用预设回复；v2.0 可选接入 AI（需 VPS 代理）

## 设计约束
- 暗色主题，CSS 变量驱动
- 手机优先（PWA 装桌面），可点击区域 ≥44px
- 简洁直观，困倦状态下可快速操作
- 无外部 CDN 依赖
