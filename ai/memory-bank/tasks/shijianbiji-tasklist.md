# 时间笔记 v1.0 — 开发任务清单（最终版）

## 规格摘要
**产品定位**：被动时间记录伙伴，通过主动问询记录日常、睡前回顾给予正反馈，帮助建立规律作息
**技术栈**：纯前端 PWA（HTML + CSS + JavaScript 原生）、localStorage 存储、GitHub Pages 部署
**目标平台**：手机（PWA 装桌面），暗色主题优先
**用户称呼**：顾顾（所有文案使用此称呼）

---

## 开发任务（共 20 项）

---

### [ ] Task 1: 项目骨架 + PWA 基础
**描述**：创建项目目录结构、index.html、全局 CSS 变量（暗色主题）、PWA manifest 和 Service Worker
**验收标准**：
- `index.html` 加载无报错
- CSS 变量定义完整（背景、文字、边框色系）
- `<meta viewport>` 移动端适配正确
- `manifest.json`：名称"时间笔记"、`display: standalone`
- `sw.js` 基本缓存策略
- 页面可添加到手机桌面
**文件**：`index.html`、`css/style.css`、`sw.js`、`manifest.json`、`assets/icon-192.png`、`assets/icon-512.png`

---

### [ ] Task 2: 数据层 — localStorage CRUD
**描述**：实现所有数据类型的本地存储（日常记录、灵感存档、设置、成就）
**验收标准**：
- 日常记录：`{id, type, content, title, timestamp, date}` 可增删查
- 灵感存档：`{id, content, timestamp, date, completed}` 可增删查改
- 用户设置：`{sleepTarget, showerWindow, inquiryInterval, styleMode, skipCount, ...}` 可读写
- 成就数据：`{stars, badges, streakDays, ...}` 可读写
- 持久化到 localStorage，刷新不丢失
- 统一 `storage.js` 工具模块导出方法
- 日期边界：凌晨 4:00 之前算昨天
**文件**：`js/storage.js`

---

### [ ] Task 3: 主界面布局 + 底部导航
**描述**：四页式主界面（时间线/回顾/成长/设置），底部导航切换
**验收标准**：
- 底部导航栏：📋时间线 / 🌙回顾 / 📊成长 / ⚙️设置
- 点击导航切换页面，无刷新
- 时间线页：按时间排列的记录列表，日期分隔
- 回顾页：睡前回顾内容区域
- 成长页：成就 + 趋势图区域
- 手机竖屏正常显示，按钮 ≥44px
**文件**：`index.html`（修改）、`css/style.css`（追加）、`js/app.js`

### [ ] Task 4: 问询弹窗 + 强制记录
**描述**：全屏居中问询弹窗，无关闭按钮，必须回应或使用有限跳过
**验收标准**：
- 弹窗无关闭按钮（×）
- 预设按钮：🎨画画 🎮游戏 📺看视频 💻写代码 📚学习 📱刷手机 🛒购物 🧹家务 🍜吃饭 💬社交 ✍️其他
- 点击预设按钮直接记录，选"其他"弹出文本框
- 三种记录方式按钮：💬说两句 / 📷拍照 / 🔗贴链接
- 拍照/链接弹出后**必须填主题**（标题输入框），补充说明可选
- 底部"跳过（今日剩余 X 次）"，剩余 0 时隐藏
- 每日零点重置跳过额度为 3 次
- 弹窗不会自动消失
**文件**：`js/inquiry.js`、`css/style.css`

---

### [ ] Task 5: 未回应重弹机制
**描述**：问询弹窗无操作时，按递增间隔持续追问
**验收标准**：
- 弹窗出现后 10 分钟无操作 → 重弹
- 仍未回应 → 30 分钟后重弹
- 持续循环直到用户回应
- 回前台后检查是否需要补弹
**文件**：`js/inquiry.js`（修改）、`js/scheduler.js`

---

### [ ] Task 6: 定时调度引擎
**描述**：基于时间的问询调度（频率、夜间切换、早上首句、日期边界）
**验收标准**：
- 根据设置频率和起始时间定时触发问询
- 晚上 8 点后自动切换文案（由语气引擎控制）
- 早上（首次唤醒）根据前一晚睡眠数据展示不同首句
- 日期边界凌晨 4:00
- 页面不在前台时不弹窗，回前台后检查
- 定时器精度 ±1 分钟可接受
**文件**：`js/scheduler.js`、`js/app.js`（初始化）

---

### [ ] Task 7: 语气/时间适配引擎
**描述**：所有文案根据时间段、用户状态、风格模式动态切换
**验收标准**：
- 早上首句三种：
  - 正常："顾顾早上好，昨晚睡得不错 ☀️"
  - 晚睡："昨晚有点晚哦。没关系，今天放轻松一点。"
  - 严重熬夜："顾顾，你昨晚几乎没睡 🫂 发生了什么？"
- 白天问询（8am-8pm）vs 晚上问询（8pm-12am）vs 凌晨安慰（1am-6am）
- 四种风格模式：温柔/严格/搞笑/简约，切换后所有文案立即生效
- 文案从 `i18n.js` 统一管理
**文件**：`js/i18n.js`、`js/scheduler.js`（修改）

### [ ] Task 8: 睡前回顾页
**描述**：目标入睡时间到达后，展示当天时间线 + 熬夜原因 + 睡前入口
**验收标准**：

- 熬夜原因 5 选 1：灵感/游戏/焦虑/不困/其他，选后可补充文字
- 下半部分"还不想睡？"四个入口：
  - 💬树洞 / 🃏塔罗 / 🌬️呼吸 / 🎵音乐
- 凌晨 1 点后额外显示安慰信息
**文件**：`js/review.js`、`css/style.css`、`index.html`（修改回顾 Tab）

### [ ] Task 9: 灵感管理员
**描述**：晚间灵感/冲动管理，三选项 + 存档次日展示
**验收标准**：
- 晚间（20:00-01:00）弹出："你现在有一件很想做的事对吧？"
- 三个按钮：存档明天 / 设倒计时 / 直接去做
- 存档内容第二天首页首屏展示，可标记已完成
- 存档超 3 天未完成自动归档
- 倒计时可选 15/30/45/60 分钟，到点提醒
**文件**：`js/inspiration.js`、`css/style.css`、`js/scheduler.js`（修改）

### [ ] Task 10: 洗澡提醒
**描述**：固定时间窗口洗澡提醒 + 追问 + 防敷衍
**验收标准**：
- 可设时间窗口（默认 22:30-23:30）
- 窗口起始弹出 + 按钮：✅已洗 / ⏰等会儿
- 等会儿 → 15 分钟后重弹
- 已洗 → 时间线自动记录
- 防敷衍：距上次弹窗不足 3 分钟回答"已洗" → 追问
- 窗口结束后不再弹
**文件**：`js/shower.js`、`js/scheduler.js`（修改）

### [ ] Task 11: 奖惩机制
**描述**：成就系统 + 温和代价
**验收标准**：
- 每日结算：连续 3 天早睡→🌟 / 连续 7 天→🏆 / 起床 5 天稳定→📊 / 日记录 ≥3→🌱

- 连续熬夜 3 天→弹出输入"我知道昨晚又熬夜了"
- 熬夜后问询频率自动 ×2（仅一天）
**文件**：`js/achievements.js`、`js/storage.js`（修改）、`js/scheduler.js`（修改）

## 质量要求
- [ ] 纯前端，零依赖，无需 npm/build
- [ ] localStorage 存储，无后端
- [ ] 手机可点击区域 ≥44px
- [ ] 暗色主题（CSS 变量驱动）
- [ ] 无外部 CDN 依赖
- [ ] 页面不在前台时不弹窗

## v1.0 不包含
- ❌ AI 聊天（v2.0 规划，需 VPS + API）
- ❌ 屏幕渐暗/系统亮度控制
- ❌ 多设备同步
- ❌ 图片内容识别

## 预期时间线
共 20 个任务，每个 30-60 分钟，预计总工时 15-20 小时。
建议顺序：Task 1-3（骨架）→ 4-7（核心问询）→ 8-10（晚间功能）→ 11-14（成长系统）→ 15-18（睡前入口）→ 19-20（收尾）
